## Limitações (ler antes de usar)

- **Âncoras sem fonte local.** Cada linha de um `LENS.md` leva `[ancora: <ficheiro>.md#<secção> | "<citação>"]`. Os `.md` referidos são transcrições processadas que **não estão neste repo**; a citação verbatim (5-15 palavras) mantém-se, mas não consegues abrir a fonte.
- **São leituras derivadas, não as palavras dos próprios.** Cada LENS é um resumo analítico construído a partir de vídeos e textos públicos de cada pessoa. Não o uses como se fosse citação ou posição oficial dela.
- **Quem não consta:** adiciona a tua pasta `<Nome>/LENS.md` a este directório (ou usa `PERSONAS_DIR`).
